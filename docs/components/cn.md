# cn

clsx + tailwind-merge. The `@aicl/fx` components compose class names through it.

**Type.** `registry:lib` · **Package.** `@aicl/fx` · **Category.** system

## Install

```bash
npx aicl add cn
```

The same item, in the shadcn registry format:

```bash
npx shadcn@latest add ./registry/r/cn.json
```

## npm import

```ts
import { cn } from '@aicl/fx';
```

## Usage

```tsx
import { cn } from '@aicl/fx';
```
