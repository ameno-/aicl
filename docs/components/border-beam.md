# BorderBeam

A light that travels around the parent border. Static under reduced motion.

**Type.** `registry:ui` · **Package.** `@aicl/fx` · **Category.** fx

## Install

```bash
npx aicl add border-beam
```

The same item, in the shadcn registry format:

```bash
npx shadcn@latest add ./registry/r/border-beam.json
```

## npm import

```ts
import { BorderBeam } from '@aicl/fx';
```

## Usage

```tsx
import { BorderBeam } from '@aicl/fx';

<div className="relative"><BorderBeam /></div>
```
