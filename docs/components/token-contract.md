# Token contract

Every visual decision as a named custom property, plus the primitive surfaces.

**Type.** `registry:theme` · **Package.** `@aicl/styles` · **Category.** theme

## Install

```bash
npx aicl add token-contract
```

The same item, in the shadcn registry format:

```bash
npx shadcn@latest add ./registry/r/token-contract.json
```

import '@aicl/styles';
