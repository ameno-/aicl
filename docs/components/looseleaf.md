# LooseLeaf skin

Paper on a desk. Values only: no JavaScript, so it cannot change behaviour.

**Type.** `registry:theme` · **Package.** `@aicl/styles` · **Category.** theme

## Install

```bash
npx aicl add looseleaf
```

The same item, in the shadcn registry format:

```bash
npx shadcn@latest add ./registry/r/looseleaf.json
```

## npm import

```ts
import '@aicl/styles/themes/looseleaf.css';
```

## Usage

```tsx
import '@aicl/styles';
import '@aicl/styles/themes/looseleaf.css';
```
